## Rules that apply here

* Nothing in this folder is final. No animation frame will be produced for any of
  these characters before an explicit approval of that character's design.
* A generated redraw is not a pixel-perfect copy of the anime. It cannot be.
* Only character 1 has reference images actually inspected (see
  `docs/02_REFERENCE_NARUTO.md`). Characters 2–10 were drawn from the dataset's
  own text fields plus general knowledge of each design; **no reference image was
  inspected for them**, and that is exactly why they are concepts and not
  proposals.

## Next step per character

`CONCEPT_ONLY → reference images inspected → proposal shown → corrections →
explicit approval → DESIGN LOCK → animation → moveset → both cameras → QA →
PLAYABLE`
